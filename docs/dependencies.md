# Approved Dependencies

Only packages listed here may be added to any workspace package.json.  To add a new dependency (or change a major version), get human / team approval first, then add a row here in the same change.

## SPFx baseline

Packages generated by the SPFx Yeoman generator are approved as a set.  Their versions are owned by SPFx and change only through an SPFx upgrade (keep all `@microsoft/sp-*` / `@microsoft/spfx-*` packages on the same version).

| Package | Version | Notes |
| --- | --- | --- |
| `@microsoft/sp-*`, `@microsoft/decorators` | SPFx version (1.23.0) | Only the ones a package actually needs |
| `@microsoft/spfx-web-build-rig`, `@microsoft/spfx-heft-plugins`, `@rushstack/heft` | per SPFx | Heft toolchain |
| `@microsoft/eslint-config-spfx`, `@microsoft/eslint-plugin-spfx`, `eslint`, `eslint-plugin-react-hooks` | per SPFx | Linting |
| `react`, `react-dom`, `@types/react`, `@types/react-dom` | 17.x | React 18 only after SPFx 1.24 |
| `typescript`, `tslib`, `@types/webpack-env`, `@types/jest`, `css-loader` | per SPFx | Build / test |
| `@fluentui/react` | ^8 (as scaffolded) | Scaffolded with React web part templates; may also be added to any other SPFx package that renders UI (e.g. application customizers, command sets) |
